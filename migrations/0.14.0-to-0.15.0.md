# Migration 0.14.0 to 0.15.0

Version 0.15.0 makes Claude Code's permission prompts follow the gates, and makes the chief of staff record outward work at once:

- **Permission rules from the gates.** Until now the gates in `org.yaml` were only rules the agents followed; Claude Code asked about nearly every command, read-only ones included. `.claude/settings.json` now holds permission rules derived from this hq's `gates:`, `repos:`, `tracker:` and `accounts.forbidden_connectors`, following the plugin's `gates/permissions.md`: what the gates leave free runs without a prompt, what needs the CEO's OK (and every write on a protected repo) always asks, notice actions ask by default. A stricter gate gives a stricter rule. The chief of staff writes the rules again whenever the gates, the repos, the board or the forbidden connectors change.
- **Record in the same turn.** Every outward write (issue, comment, pull request) and every decision the CEO takes in chat is recorded in the hq, and committed, in the same turn. Recording is never deferred to the end of a session or of a batch; batching stays allowed for routing work.

No schema changes: `org.yaml` stays `org/5` and `company/state.md` stays `state/1`.

Apply the sections below in order. In the hq the template placeholders are already rendered, so each edit names a fragment without placeholders. Where a fragment is not found exactly (the CEO edited that part), do not guess: show the CEO the current text and the intended result, and ask.
